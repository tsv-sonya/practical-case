# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с возможностью хранения данных в JSON-файле.

## Возможности

- Добавление новых книг (автор, название, оценка 1-5, дата прочтения)
- Просмотр списка всех книг
- Подсчёт средней оценки
- Статистика по авторам (количество книг, средняя оценка)
- Удаление книг

## Структура приложения

```
├── main.py      # Точка входа, текстовое меню
├── models.py    # Класс Book с валидацией
├── storage.py   # Чтение/запись JSON, поиск, удаление
├── stats.py     # Подсчёт статистики
├── books.json   # Хранилище данных
└── README.md    # Документация
```

## Запуск

```bash
python main.py
```

